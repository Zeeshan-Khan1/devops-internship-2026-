# VirtualBox & Ubuntu CLI Virtual Machine

## Overview

As my first internship task, I installed Oracle VirtualBox on my laptop and created a command-line based Ubuntu virtual machine. The purpose of this task was to become familiar with virtualization and Linux server environments and to establish a foundation for further Linux administration and infrastructure-related practical work.

## Objectives

- Install VirtualBox
- Understand basic virtualization concepts
- Create a virtual machine
- Install Ubuntu in a virtual environment
- Configure a CLI-based Ubuntu environment
- Access and work with Ubuntu through the terminal
- Become familiar with basic Linux commands

## Tools Used

- Oracle VirtualBox
- Ubuntu
- Host Operating System: Ubuntu/Linux
- Virtual Machine

## Implementation

### 1. Installed VirtualBox

Installed Oracle VirtualBox on the host machine to create and manage virtual machines.

### 2. Created Ubuntu Virtual Machine

Created a new virtual machine and configured the required resources such as:

- RAM
- CPU
- Virtual hard disk
- Network adapter

### 3. Installed Ubuntu

Attached the Ubuntu ISO image to the virtual machine and completed the Ubuntu installation.

### 4. CLI-Based Environment

Configured and accessed Ubuntu through the command-line interface instead of relying on a graphical desktop environment.

### 5. Linux Practice

Used the terminal to practice basic Linux commands and navigate the Ubuntu environment.

## Learning Outcomes

Through this task, I learned:

- Basics of virtualization
- Virtual machine creation and configuration
- Ubuntu installation
- CLI-based Linux environments
- Basic terminal interaction
- Virtual machine resource allocation
- The relationship between a host machine and a virtual machine
